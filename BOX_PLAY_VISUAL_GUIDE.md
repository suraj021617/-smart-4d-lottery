## Pro Tips

```
💡 TIP 1: Check Box Hit Rate First
   ├─ Strong (>30%): Worth playing box
   ├─ Moderate (15-30%): Play top 3 perms
   └─ Weak (<15%): Play main only

💡 TIP 2: Use Backup Options Wisely
   ├─ If main misses, try backups
   ├─ Lower confidence but still valid
   └─ Cost-effective fallback

💡 TIP 3: Track 3-Digit Matches
   ├─ High count = number is "hot"
   ├─ Consider playing more perms
   └─ Partial wins are still wins

💡 TIP 4: Budget Management
   ├─ Start with main only (RM5)
   ├─ Add box if budget allows (RM35)
   ├─ Don't overextend
   └─ Play smart, not hard

💡 TIP 5: Combine Strategies
   ├─ Play main from Quick Pick
   ├─ Use box as backup
   ├─ Use 3-digit as last resort
   └─ Maximize coverage within budget
```
