# 🚀 QUICK START GUIDE

## Installation (30 seconds)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the app
python app.py

# 3. Open browser
# Go to: http://127.0.0.1:5000
```

---

## First Prediction (1 minute)

1. **Select Date**: Click "Tomorrow" button
2. **Run Prediction**: Click "ALL (Consensus)" button
3. **View Results**: See Top 5 predictions
4. **Save Log ID**: Note the log ID for later evaluation

---

## After Result Announced (30 seconds)

1. **Enter Log ID**: Paste the log ID from earlier
2. **Enter Result**: Type the actual 4-digit winning number
3. **Evaluate**: Click "Evaluate" button
4. **Auto-Learn**: System automatically updates weights

---

## View Performance (10 seconds)

1. Click "Load Leaderboard"
2. See which predictors are performing best
3. System adapts based on this data

---

## Individual Predictors

Try each button to see different prediction methods:

- **📊 Recent Stats**: Last 100-300 draws
- **📈 Last 3 Years**: 3-year window
- **🎯 Last 5 Years**: 5-year window (recommended)
- **🤖 ML Predictor**: Machine learning
- **🧠 AI Pattern**: Pattern recognition
- **⚡ Smart Auto-Learn**: Adaptive consensus
- **📚 Full History**: All historical data
- **🔥 ALL (Consensus)**: Combined predictions
